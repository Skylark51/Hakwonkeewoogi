# 학원키우기 (Hakwonkeewoogi)

Football Manager / 야구9단 계열의 데이터 중심 학원 경영 시뮬레이션 프로토타입입니다.

현재 버전은 **v0.2 core loop prototype**입니다.

## 현재 플레이 흐름

```text
인트로
  ↓
학원 이름 / 주력 과목 선택
  ↓
원장 1인 개원
  ↓
학생 상담 → 등록/거절
  ↓
강사 채용
  ↓
주간 트레이닝 선택
  ↓
1주 진행
  ↓
학생 성장 / 스트레스 / 만족도
  ↓
재정 / 시설 / 평판 / 경쟁학원 / 이벤트
  └────────────────────→ 반복
```

## v0.2 구현 기능

### 인트로
- 게임 시작 인트로
- 게임 안에서 **인트로 직접 편집**
- C++ 코드를 수정하지 않고 일반 텍스트처럼 입력
- 편집한 문구는 PC에 저장되어 다음 실행에도 유지

### 개원
- 학원 이름 설정
- 주력 과목: 수학 / 영어 / 국어 / 과학
- 시작 자금 3,500만원
- 강의실 1개, 정원 18명
- 최초 강사 0명
- 원장이 주력 과목 직접 강의

### 학생 상담
상담 학생마다 다음 정보가 다릅니다.

- 현재 성적
- 잠재력
- 성실성
- 이해력
- 암기력
- 집중력
- 시험 적응력
- 스트레스
- 피로
- 만족도
- 출석
- 상담 적합도
- 학부모 요구 수준
- 상담 메모

플레이어가 학생을 직접 등록하거나 거절합니다.

### 강사
강사 후보마다 다음 특성이 있습니다.

- 담당 과목
- 강의력
- 상담 능력
- 학생 관리
- 스타성
- 체력
- 월 급여
- 계약금
- 캐릭터 특성

현재 예시 특성:

- 스타강사형
- 엄격한 관리형
- 친근한 상담형
- 연구·교재형
- 체력 좋은 열정형
- 무난한 균형형

### 트레이닝
매주 운영 방침을 선택합니다.

- 균형 운영
- 성적 집중
- 기초 강화
- 컨디션 관리

성적 집중은 성장률이 높지만 스트레스/피로가 빠르게 증가합니다.
컨디션 관리는 성장률을 일부 포기하고 학생 상태를 회복합니다.

### 시설
- 강의실 확장
- 인테리어 개선
- 자습실 개선
- 강의실 수에 따른 최대 정원 변화

### 재정
주간 결산에 다음 항목이 반영됩니다.

- 수강료
- 강사 급여
- 임대료
- 전기세
- 수도세
- 시설 유지비
- 시설 투자비
- 강사 계약금

### 경쟁학원
- 경쟁 학원의 주력 과목
- 평판
- 재학생 수
- 매주 상태 변화
- 우리 학원과의 평판/학생 수 비교

### 주간 이벤트
학원 규모와 학생 상태에 따라 이벤트가 발생합니다.

예:
- 정원 부족
- 학생 스트레스 과다
- 학부모 커뮤니티 입소문
- 경쟁학원 공격적 홍보
- 시설 소모품 교체

## 빌드

### 요구사항
- CMake 3.24+
- C++20 compiler
- Qt 6.x Widgets

### Windows

```bash
cmake -S . -B build
cmake --build build --config Release
```

GitHub Actions도 Windows x64 빌드와 Qt runtime 패키징을 수행합니다.

## 브라우저 실행

현재 데스크톱 버전은 C++/Qt native 애플리케이션입니다.
향후 WebAssembly 타깃을 분리하면 동일한 시뮬레이션 코어를 GitHub Pages에서도 사용할 수 있습니다.

## 개발 원칙

- 시뮬레이션 로직과 UI를 분리
- 기능 없이 이름만 있는 더미 시스템을 만들지 않음
- 실제 플레이 루프에 연결되는 시스템부터 구현
- 불필요한 폴더/파일을 늘리지 않음
- 장기적으로 SQLite 기반 세이브/로드와 데이터 분리를 진행
