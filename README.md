# 학원키우기 (Hakwonkeewoogi)

Football Manager / 야구9단 계열의 데이터 중심 학원 경영 시뮬레이션 프로토타입입니다.

현재 버전은 **v0.3 academy scene & weekly class cycle prototype**입니다.

## v0.3 핵심 플레이 흐름

```text
인트로
  ↓
학원명 / 원장 주력 과목 선택
  ↓
주력 과목 단과학원 개원
  ↓
학생 상담 · 강사 채용 · 과목 개설 · 수강료 설정
  ↓
시설 구성 · 주간 트레이닝 선택
  ↓
[강의 시작 · 1주 진행]
  ↓
학원 내부에서 학생 이동 / 수업 애니메이션
  ↓
학생 성장 · 재정 · 평판 · 상담 유입 · 퇴원 · 시험 처리
  ↓
주간 리포트 + 다음 주 팁
  └────────────────────────────→ 반복
```

## 메인 학원 화면

메인 탭에서 학원 내부를 탑다운 픽셀 RPG 형태로 표시합니다.

- 등록 학생 캐릭터 표시
- 학생 캐릭터 상시 이동
- 강의 시작 시 책상으로 이동
- 수업 중 간단한 공부 모션
- 수업 종료 후 다시 이동
- 시설을 만들면 실제 학원 평면에 방이 추가됨

별도 게임 엔진 없이 Qt Painter로 직접 그려 가볍게 유지합니다.

## 과목 개설

처음에는 원장 주력 과목 하나만 개설됩니다.

예:
- 원장 주력 = 수학 → 수학 상담만 유입
- 영어 강사 채용 → 영어를 **직접 개설**할 수 있음
- 영어 개설 후 → 영어 상담 유입 시작

강사를 채용했다고 과목이 자동 개설되지는 않습니다.

현재 과목:
- 수학
- 영어
- 국어
- 과학
- 사회

## 학생 잠재력

학생 잠재력은 균등분포가 아닙니다.

- 일반 잠재력 학생이 대부분
- 잠재력 80대는 비교적 드묾
- 잠재력 90 이상은 매우 드묾
- 새 게임 첫 상담 풀에는 잠재력 90 이상 학생 1명 보장

이후에는 높은 잠재력 학생도 정상 확률로만 등장합니다.

## 게임 기준 월 수강료

주 3회 단과 운영을 가정한 게임 내 시장 기준가:

| 과목 | 월 기준가 |
| --- | ---: |
| 수학 | 400,000원 |
| 영어 | 400,000원 |
| 국어 | 300,000원 |
| 과학 | 250,000원 |
| 사회 | 250,000원 |

게임에서는 각 기준가의 60~120% 범위에서 가격을 조정합니다.

### 가격 효과

수강료 인하:
- 상담 유입 증가
- 상담 적합도 상승
- 학생당 매출 감소

수강료 인상:
- 학생당 매출 증가
- 상담 유입 감소
- 지역 평판 부담
- 기존 학생 퇴원 확률 증가

실제 대한민국 학원 교습비는 전국 단일 월 금액 상한으로 운영되지 않으며, 관할 교육지원청의 교습비 조정기준과 등록·변경 절차를 따릅니다. 게임 수치는 현실 법정 상한이 아니라 밸런스를 위한 시장 기준값입니다.

## 시설

시설은 단순 인테리어 레벨만 올리는 방식에서 방 단위로 확장되었습니다.

- 학원 면적 확장
- 강의실 추가
- 원장실
- 상담실
- 탕비실
- 자습실
- 전체 인테리어 개선

효과:
- 강의실 → 최대 학생 정원
- 상담실 → 상담 유입 / 상담 적합도
- 탕비실 → 피로 / 스트레스 관리
- 자습실 → 성장 / 컨디션 보조
- 인테리어 → 만족도 / 평판
- 면적 확장 → 설치 가능한 방 슬롯 증가

방을 늘릴수록 임대료·전기세·시설 유지비도 함께 증가합니다.

## 시험

평소 표시되는 **학업능력**과 실제 **시험점수**를 분리했습니다.

내신시험:
- 4월
- 7월
- 9월
- 12월

해당 월 4주차에 시험을 실시합니다.

시험점수는 다음 요소의 영향을 받습니다.

- 현재 학업능력
- 시험 적응력
- 스트레스
- 피로
- 무작위 시험 변동

향후 고등부/수능반을 별도 트랙으로 만들면서 3·5·6·7·9·10월 학력평가/모의평가를 연결할 예정입니다.

## 주간 리포트

한 주가 끝나면 다음 항목을 표시합니다.

- 현금 변화
- 평판 변화
- 학업능력 변화
- 만족도 변화
- 신규 상담 수
- 퇴원 수
- 시험 실시 여부 및 평균점수
- 주요 이벤트
- 다음 주 운영 팁

## 빌드

### 요구사항
- CMake 3.24+
- C++20 compiler
- Qt 6.x Widgets

### Windows

```bash
cmake -S . -B build
cmake --build build --config Release
```

GitHub Actions에서 Windows x64 빌드와 Qt runtime 패키징을 자동 검증합니다.

## 개발 원칙

- 시뮬레이션 로직과 UI 분리
- 실제 효과 없는 더미 메뉴를 만들지 않음
- 기능을 기존 주간 루프에 연결한 뒤 추가
- 불필요한 폴더를 늘리지 않음
- 그래픽은 현재 Qt 기반 경량 2D 화면으로 유지
- 규모가 커지는 시점에 SQLite save/load 도입
