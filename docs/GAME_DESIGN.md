# 학원키우기 게임 설계

## 현재 방향

학원키우기는 데이터 중심 경영 시뮬레이션에 **탑다운 학원 생활 화면**을 결합한다.

두 화면이 분리된 게임이 아니라 동일한 데이터를 공유한다.

```text
경영 데이터
   ↕
학원 내부 화면
   ↕
학생 / 강사 / 시설 / 수업
```

메인 화면에서 학생들이 실제로 돌아다니고 수업을 받는 모습이 보이되,
핵심 게임성은 학생 육성, 강사 채용, 과목 확장, 가격 결정, 시설 투자와 경쟁학원 대응에 둔다.

---

## 1. 메인 학원 Scene

### 표현
- 탑다운 2D
- 픽셀 RPG 감성
- 외부 에셋 의존 최소화
- Qt Painter 직접 렌더

### 학생
- 등록 즉시 Scene에 등장
- 평상시 학원 내 이동
- 강의 시작 시 강의실 책상으로 이동
- 수업 중 공부 모션
- 수업 종료 후 다시 자유 이동

### 시설
시설 건설 상태를 Scene에 직접 반영한다.

- 강의실
- 원장실
- 상담실
- 탕비실
- 자습실

향후:
- 화장실
- 교무실
- 자료실
- 휴게실
- PC실

---

## 2. 주간 운영 Cycle

플레이어는 실시간으로 시간을 흘려보내지 않는다.

관리 단계:
1. 학생 상담
2. 강사 채용
3. 과목 개설/폐강
4. 수강료 조정
5. 시설 투자
6. 주간 트레이닝 설정

그 다음:

```text
강의 시작
→ 학생 이동 애니메이션
→ 수업 애니메이션
→ 1주 시뮬레이션
→ 주간 리포트
→ 다음 주
```

---

## 3. 과목 개설

신규 상담 유입은 **개설 과목만** 대상으로 한다.

초기:
- 원장 주력 과목 1개만 개설

다른 과목:
1. 해당 과목 강사 채용
2. 과목 개설
3. 다음 주부터 해당 과목 상담 유입

현재 과목:
- 수학
- 영어
- 국어
- 과학
- 사회

---

## 4. 수강료

게임 시장 기준 월 수강료:

- 수학 400,000원
- 영어 400,000원
- 국어 300,000원
- 과학 250,000원
- 사회 250,000원

주 3회 단과 운영을 가정한다.

게임상 조정 범위:
- 시장 기준의 60~120%

### 가격 탄력성

가격 ↓
- 상담 요청 ↑
- 상담 적합도 ↑
- 매출/학생 ↓

가격 ↑
- 매출/학생 ↑
- 상담 요청 ↓
- 지역 평판 ↓
- 기존 학생 퇴원 위험 ↑

실제 교습비 규정은 교육지원청별 교습비 조정기준과 등록절차를 사용하므로,
게임상 가격 제한은 현실 법정 상한이 아닌 밸런스 규칙이다.

---

## 5. 학생 등장 확률

잠재력을 균등분포로 만들지 않는다.

대략적인 생성 계층:
- 50~67: 다수
- 68~79: 중간
- 80~89: 희귀
- 90~97: 매우 희귀

첫 게임 시작:
- 잠재력 90 이상 1명 보장

이후:
- 일반 생성 확률만 사용

향후 평판이 높아지면 상위 잠재력 학생 유입률을 조금 높일 수 있다.

---

## 6. 시설

### 공간 슬롯
학원은 무한히 방을 만들 수 없다.

```text
현재 면적
→ 사용 가능한 방 슬롯
→ 방 설치
```

빈 공간이 없으면 먼저 학원 면적을 확장해야 한다.

### 시설 효과

강의실
- 정원 증가

원장실
- 경영/평판 보조

상담실
- 상담 유입 증가
- 상담 적합도 증가

탕비실
- 피로 관리
- 스트레스 관리

자습실
- 학업 성장 보조
- 컨디션 보조

인테리어
- 학생 만족도
- 상담 인상
- 평판

면적/시설 증가:
- 임대료
- 전기세
- 유지비
증가

---

## 7. 시험과 성장

### 학업능력
매주 변화하는 장기 성장 수치.

### 시험점수
정해진 시험 시기에만 새로 생성되는 결과값.

현재 내신:
- 4월
- 7월
- 9월
- 12월

시험점수:

```text
학업능력
+ 시험 적응력
- 스트레스
- 피로
+ 시험 당일 변동
```

### 고등부 확장 예정

고등부/수능반을 추가하면 다음 평가 이벤트를 별도로 연결한다.

- 3월 학력평가
- 5월 학력평가(고3)
- 6월 모의평가
- 7월 학력평가
- 9월 모의평가
- 10월 학력평가
- 수능

중등/내신반과 고등/수능반을 같은 시험달력으로 처리하지 않는다.

---

## 8. 주간 리포트

주간 리포트는 다음 주 의사결정을 위한 핵심 UI다.

표시:
- 현금 증감
- 평판 증감
- 학업능력 증감
- 만족도 증감
- 신규 상담
- 퇴원
- 시험결과
- 주간 이벤트
- 다음 주 팁

Tip은 단순 랜덤 문장이 아니라 현재 상태에서 생성한다.

예:
- 정원 거의 가득 참 → 강의실 추가 권장
- 스트레스 높음 → 컨디션 관리 권장
- 수강료 높음 → 가격/퇴원 점검
- 상담 부족 → 가격/상담실/과목확장 점검
- 신규 강사 확보 → 과목 개설 안내

## 구현 원칙

- 기능 없이 이름만 있는 폴더/클래스를 만들지 않는다.
- Scene은 시뮬레이션 데이터를 그대로 시각화한다.
- 새 시스템은 주간 루프와 재정/평판에 연결한다.
- 지나친 엔진 의존 없이 가볍게 유지한다.
